# puz-grabber
A tool to download .puz crossword puzzle files from sites that make them available for download via link

## Uses
Folks who want to get `.puz` files from sites with embedded crossword puzzles should refer to [xword-dl](https://github.com/thisisparker/xword-dl) by [@thisisparker](https://github.com/thisisparker). This repo is a CLI option for downloading `.puz` files from outlets or websites that actively provide a `.puz` download link (eg, [Chrosshare](https://crosshare.org)).
