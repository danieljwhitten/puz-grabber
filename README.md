# puz-grabber
A tool to download .puz crossword puzzle files from sites that make them available for download via link

## Uses
Folks who want to get `.puz` files from sites with embedded crossword puzzles should refer to [xword-dl](https://github.com/thisisparker/xword-dl) by [@thisisparker](https://github.com/thisisparker). This repo is a CLI option for downloading `.puz` files from outlets or websites that actively provide a `.puz` download link (eg, [CROSSHARE](https://crosshare.org)).

## Sources
+ `bc`: [Black Crossword](https://www.blackcrossword.com/) [NB: Please play on their site if you can, included for archive purposes]
+ `cds`: [Columbia Daily Spectator](https://crosshare.org/CUDailySpectator)
+ `cs`: [CROSSHARE Daily Mini](https://crosshare.org/dailyminis) [NB: The date assigned to the downloaded puzzle is the date it was featured as the daily mini, which may or may not be the original publish date]
+ `dc` [Duke Chronicle](https://crosshare.org/chroniclecrossword)
+ `npm` [Nebraska Public Media Labs](https://crosshare.org/npmlabs)
+ `td`,`tdm`: [Tufts Daily](https://www.tuftsdaily.com/section/crossword) [`td` gets the latest full crossword, `tdm` gets the latest mini crossword]
+ `que`: [Queerty](https://www.queerty.com/tag/crossword/)

Use `all` to download latest puzzles for all listed sources.
